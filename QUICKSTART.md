# Quick Start Guide

## First Time Setup

```bash
cd ~/two-ex
npm install
```

## Start Development Server

```bash
npm run dev
```

Open http://localhost:5173 in your browser!

## Make Changes

- **Edit schedule**: `src/data/itinerary.js`
- **Edit packing list**: `src/data/packingList.js`
- **Add photos**: `public/assets/photos/` + update `src/components/PhotoGallery.jsx`
- **Add images**: `public/assets/images/` + update components
- **Change colors**: `tailwind.config.js`
- **Update components**: `src/components/`

## Build for Production

```bash
npm run build
```

## Deploy

```bash
# Easy deploy with Vercel
npm install -g vercel
vercel
```

## Test Easter Eggs

1. **Ewok**: Scroll past 50% of the page
2. **Konami Code**: Type ↑↑↓↓←→←→BA on your keyboard
3. **Coors Light**: Appears on page load (top-right corner)

## Keyboard Navigation

- **Lightbox photos**: ← → arrow keys, ESC to close
- **Smooth scrolling**: Click navigation buttons in hero
